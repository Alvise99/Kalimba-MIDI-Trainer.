# Kalimba MIDI Trainer

App Android gratuita per imparare a suonare una kalimba reale a 17 tasti.

## Funzionalità
- Riconoscimento delle note tramite microfono
- Importazione di file MIDI
- Esercizi interattivi
- Note sincronizzate con la musica
- Accompagnamento musicale
- Kalimba a 17 tasti in Do maggiore
- Allenamento con controllo degli errori

## Obiettivo
Creare un'app Android nativa installabile tramite APK.
